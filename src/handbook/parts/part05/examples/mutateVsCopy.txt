Goal              Mutates (avoid in state)     Returns a new array (use this)
----------------  ---------------------------  ------------------------------------------
Add an item       arr.push(item)               [...arr, item]
Remove an item    arr.splice(i, 1)             arr.filter(x => x.id !== id)
Replace an item   arr[i] = newItem             arr.map(x => x.id === id ? newItem : x)
Change one field  arr[i].stock = 0             arr.map(x => x.id === id ? { ...x, stock: 0 } : x)
Sort              arr.sort()                   [...arr].sort()
Change an object  order.status = 'approved'    { ...order, status: 'approved' }
